Ferrez Guiding

A mobile-first booking website for a Cape Town hiking guide.

A custom-built website for Ferrez Guiding, a Cape Town hiking guide on Table Mountain and Lion's Head. Visitors compare six routes, check sunrise and sunset times, then build a ready-made WhatsApp booking message in a few taps. It is designed for phones, works without JavaScript, and lets the owner update reviews by editing one plain text file, with no tools.

  • HTML
  • CSS
  • JavaScript
  • No framework

Tally

The gym game that rewards showing up, and ranks you against people your size.

Tally is an interactive demo of a gym membership and loyalty app. Members book classes, check in with a wallet card, keep weekly streaks and climb plate-colour ranks within their weight class. Owners get a full-screen dashboard showing money, attendance and members drifting away. The gym, its members and all figures are invented, so anyone can explore every screen freely.

  • HTML
  • CSS
  • JavaScript

Dashboard

The control panel for running a small website business, from first lead to final invoice.

A private dashboard for running a small website design business. It tracks leads, jobs and clients, builds quotes from a price list, issues invoices and records payments. Insights show the pipeline, profit and what needs attention today. Passkey login keeps it secure, it works on phone and laptop, and every figure shown here is made-up demo data for this portfolio.

  • JavaScript
  • Cloudflare Workers
  • D1 database
  • Passkeys

Kirkgate Heating & Plumbing

A local plumber's website that takes enquiries and deposits, and answers questions at any hour.

A demo website for a made-up Aberdeen plumbing and heating firm. Visitors can send an enquiry, pay a £25 call-out deposit in test money, or ask a chatbot that only answers from approved facts. If someone mentions gas or fire, ordinary code shows real emergency numbers before any AI runs. Nothing is sold, and the chatbot's spending is capped daily.

  • Next.js
  • TypeScript
  • Stripe test mode
  • AI chatbot
